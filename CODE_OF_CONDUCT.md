# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(v2.1). In short: be respectful and constructive. Harassment, discrimination, and
personal attacks are not tolerated.

Report unacceptable behaviour to the maintainer via a
[private security advisory](https://github.com/svrforum/bebe-moment/security/advisories/new)
or a direct message. Maintainers may remove comments, commits, issues, and PRs
that violate this code, and may ban repeat offenders.
